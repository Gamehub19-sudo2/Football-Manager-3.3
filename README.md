Football Manager 1.6 — Craques Caríssimos

Como jogar: extraia o ZIP e abra o arquivo index.html em um navegador atualizado.

Novidades:
- Preços dos craques aumentados para centenas de milhões.
- Jogadores comuns também estão muito mais caros.
- Estádio com 100 níveis e melhorias progressivamente mais caras.
- Campo de futebol completo visível na tela principal.
- Dificuldade ajustada para partidas mais equilibradas e placares menos exagerados.
- Ganhos por partida reajustados para ajudar a evoluir o clube.

O progresso fica salvo no armazenamento local do navegador.
